# 外部系统调用审核接口指南

## 接口地址

**提交审核接口**: `POST /api/v1/audit/submit`

这是外部系统用来提交审核数据的HTTP接口。

## 快速示例

### 提交酒店订单审核

```bash
curl -X POST http://localhost:8080/api/v1/audit/submit \
  -H "Content-Type: application/json" \
  -H "X-User-ID: 1001" \
  -H "X-User-Name: 张三" \
  -d '{
    "business_type": 2,
    "business_id": 10001,
    "apply_reason": "订单金额异常，需要人工审核",
    "hotel_order": {
      "hotel_id": 5001,
      "hotel_name": "北京希尔顿酒店",
      "hotel_address": "北京市朝阳区建国路1号",
      "room_type": "豪华大床房",
      "check_in_time": "2024-01-20T14:00:00Z",
      "check_out_time": "2024-01-22T12:00:00Z",
      "guest_name": "张三",
      "guest_id_card": "110101199001011234",
      "order_amount": 2888.00
    }
  }'
```

### 响应示例

成功响应：
```json
{
  "code": 0,
  "message": "提交成功",
  "data": {
    "audit_id": 12345,
    "business_type": 2,
    "business_id": 10001,
    "audit_status": 1,
    "submit_time": "2024-01-20T10:30:00Z"
  }
}
```

失败响应：
```json
{
  "code": 400,
  "message": "请求参数错误: 酒店订单信息不能为空"
}
```

## 完整请求参数说明

### 公共参数

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| business_type | int | 是 | 业务类型：1=车票订单，2=酒店订单，3=酒店入驻 |
| business_id | int | 是 | 业务ID（订单ID或酒店ID） |
| apply_reason | string | 是 | 申请原因，最多255字符 |

### 酒店订单参数 (business_type=2)

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| hotel_order.hotel_id | int | 是 | 酒店ID |
| hotel_order.hotel_name | string | 是 | 酒店名称 |
| hotel_order.hotel_address | string | 是 | 酒店地址 |
| hotel_order.room_type | string | 否 | 房间类型 |
| hotel_order.check_in_time | string | 否 | 入住时间（ISO 8601格式） |
| hotel_order.check_out_time | string | 否 | 退房时间（ISO 8601格式） |
| hotel_order.guest_name | string | 否 | 入住人姓名 |
| hotel_order.guest_id_card | string | 否 | 入住人身份证号 |
| hotel_order.order_amount | float | 是 | 订单金额（元） |
| hotel_order.hotel_extra | string | 否 | 扩展字段（JSON格式） |

### 酒店入驻参数 (business_type=3)

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| hotel_settle.hotel_id | int | 是 | 酒店ID |
| hotel_settle.hotel_name | string | 是 | 酒店名称 |
| hotel_settle.hotel_address | string | 是 | 酒店地址 |
| hotel_settle.business_license | string | 是 | 营业执照编号 |
| hotel_settle.hotel_extra | string | 否 | 扩展字段（JSON格式） |

## Go语言调用示例

```go
package main

import (
    "bytes"
    "encoding/json"
    "fmt"
    "net/http"
)

type SubmitAuditRequest struct {
    BusinessType int8            `json:"business_type"`
    BusinessID   uint64          `json:"business_id"`
    ApplyReason  string          `json:"apply_reason"`
    HotelOrder   *HotelOrderInfo `json:"hotel_order,omitempty"`
}

type HotelOrderInfo struct {
    HotelID      uint64  `json:"hotel_id"`
    HotelName    string  `json:"hotel_name"`
    HotelAddress string  `json:"hotel_address"`
    RoomType     string  `json:"room_type"`
    OrderAmount  float64 `json:"order_amount"`
}

func SubmitHotelAudit() {
    // 构造请求
    req := SubmitAuditRequest{
        BusinessType: 2,
        BusinessID:   10001,
        ApplyReason:  "订单金额异常，需要人工审核",
        HotelOrder: &HotelOrderInfo{
            HotelID:      5001,
            HotelName:    "北京希尔顿酒店",
            HotelAddress: "北京市朝阳区建国路1号",
            RoomType:     "豪华大床房",
            OrderAmount:  2888.00,
        },
    }

    // 序列化为JSON
    jsonData, _ := json.Marshal(req)

    // 创建HTTP请求
    httpReq, _ := http.NewRequest(
        "POST",
        "http://localhost:8080/api/v1/audit/submit",
        bytes.NewBuffer(jsonData),
    )
    httpReq.Header.Set("Content-Type", "application/json")
    httpReq.Header.Set("X-User-ID", "1001")
    httpReq.Header.Set("X-User-Name", "张三")

    // 发送请求
    client := &http.Client{}
    resp, err := client.Do(httpReq)
    if err != nil {
        fmt.Println("请求失败:", err)
        return
    }
    defer resp.Body.Close()

    // 解析响应
    var result map[string]interface{}
    json.NewDecoder(resp.Body).Decode(&result)
    fmt.Println("响应:", result)
}
```

## 查询审核结果

提交成功后，可以通过返回的 `audit_id` 查询审核状态：

```bash
# 查询审核详情
curl http://localhost:8080/api/v1/audit/12345

# 查询审核列表
curl "http://localhost:8080/api/v1/audit/list?business_id=10001"
```

## 注意事项

1. **请求头**: 需要在请求头中传递 `X-User-ID` 和 `X-User-Name` 标识提交人
2. **业务类型**: 根据不同的 `business_type`，需要传递对应的业务数据
3. **时间格式**: 时间字段使用ISO 8601格式（如：2024-01-20T14:00:00Z）
4. **金额精度**: 金额字段保留2位小数
5. **身份证号**: 系统会自动对身份证号进行脱敏处理
6. **幂等性**: 相同的 `business_type` 和 `business_id` 只能提交一次审核

## 错误码说明

| 错误码 | 说明 |
|--------|------|
| 0 | 成功 |
| 400 | 请求参数错误 |
| 500 | 服务器内部错误 |
